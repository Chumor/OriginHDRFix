# OriginHDRFix

[English](README_EN.md) | **简体中文**

OriginHDRFix 是一个适用于 OriginOS 的 KernelSU 模块，旨在为受支持的应用恢复 HDR 高亮显示效果。

## 安装

1. KernelSU 需要安装并启用 metamodule 才能挂载本模块，推荐使用：
   - [meta-magic_mount-rs](https://github.com/Tools-cx-app/meta-magic_mount-rs)
   - [meta-hybrid_mount](https://github.com/Hybrid-Mount/meta-hybrid_mount)
2. 安装 OriginHDRFix
3. 重启设备
