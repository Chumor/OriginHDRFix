# OriginHDRFix

**English** | [简体中文](README.md)

OriginHDRFix is a KernelSU module for OriginOS that aims to restore HDR highlight rendering in supported applications.

## Installation

1. KernelSU requires a metamodule to be installed and enabled in order to mount this module. The following metamodules are recommended:
   - [meta-magic_mount-rs](https://github.com/Tools-cx-app/meta-magic_mount-rs)
   - [meta-hybrid_mount](https://github.com/Hybrid-Mount/meta-hybrid_mount)
2. Install OriginHDRFix.
3. Reboot your device.
